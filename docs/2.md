要让整个交互体验完全对标 Claude Code（克制、流畅、信息分级明确），我们需要在 ChatRenderer 和 tui_app.py 之间建立一套非常清晰的状态切换指令。

以下是四个核心生命周期的 UI 表现和对应的驱动逻辑（以你喜欢的极简冷色调为主，底部状态栏使用 dim cyan 和 white）：

1. 初始打开 (Welcome State)
视觉表现：完全留白，或者只有一行极简的淡蓝色欢迎语，视线直接聚焦在底部的输入框。状态栏显示当前默认的 Volcengine 模型。

│                                                            │
│                                                            │

│  [dim cyan]volcengine-doubao-pro[/dim cyan] [dim white]· 就绪[/dim white]                         │
└────────────────────────────────────────────────────────────┘
驱动命令 (Renderer -> TuiApp)：

renderer.render_welcome(): 往 ContentBuffer 推送一行暗色提示。

tui_app.set_status_text("volcengine-doubao-pro · 就绪", style="class:status.ready")

2. 发送消息 & 思考中 (Thinking State)
视觉表现：用户的输入被“推”到上方内容区，保留 You > 前缀。底部输入框暂时清空或锁定。内容区底部出现平滑的 Spinner 动画。

└────────────────────────────────────────────────────────────┘
驱动命令：

REPL 捕获 Enter，把输入文本喂给 Session。

renderer.handle(turn_start_event)

将用户输入以 [bold]You >[/bold] {text} 格式追加到 ContentBuffer。

ContentBuffer.start_spinner("[dim cyan]⠋ 思考中...[/dim cyan]")

tui_app.set_status_text("volcengine-doubao-pro · 运行中...", style="class:status.running")

3. 流式输出 & 工具调用 (Streaming & Tool Use State)
视觉表现：Spinner 被真实的文本或工具调用替换。工具调用要极度克制（单行、暗色），避免刷屏。文本流式追加时，依靠 tui_app 的 ScrollablePane 自动把最新内容顶上来。

│  You >                                                     │
│  [dim cyan]volcengine-doubao-pro[/dim cyan] [dim white]· 运行中...[/dim white]                      │
└────────────────────────────────────────────────────────────┘
驱动命令：

收到 Tool Use: renderer.handle(tool_use_event) -> ContentBuffer.stop_spinner() -> 追加单行暗色工具日志 -> 重新 start_spinner("⏳ 执行中...")。

收到 Text: renderer.handle(text_event) -> ContentBuffer.stop_spinner() -> 追加纯文本流（如果用到 Buffer 策略，在此处处理换行）。

在每次 handle 结束后，调用 tui_app.update_content() 触发重绘。

4. 轮次结束 (Turn End / Complete State)
视觉表现：文本输出完毕，如果是 Markdown 则进行一次最终的精渲染（可选）。底部状态栏闪烁一下，更新 Token 消耗和耗时。重新聚焦等待下一轮输入。

└────────────────────────────────────────────────────────────┘
驱动命令：

renderer.handle(turn_end_event)

ContentBuffer.stop_spinner()

调用 Markdown 渲染（如果你保留了 Buffer 精渲染策略），替换刚才的纯文本。

tui_app.set_status_text("volcengine-doubao-pro · 1 次工具 · in=1.2k out=450 · ⏱️ 3.2s", style="class:status.ready")

tui_app.focus_input() 确保光标回到输入行。

这个流程把视觉噪音降到了最低，只有真正需要你关注的代码和思路是高亮的。
